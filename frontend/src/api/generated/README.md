# Generated API types

`catalog.ts`, `reporting.ts`, `policyengine.ts` and `autodelete.ts` are generated by
[openapi-typescript](https://github.com/openapi-ts/openapi-typescript) (MIT) from the committed OpenAPI
contracts in the main repository, `docs/api/openapi/<service>.json`. Do not edit them by hand.

The contracts themselves are generated from the Spring controllers by each service's
`OpenApiSpecExportTest`; a CI guard (`scripts/ci-guards/post-test/openapi-drift.sh`) fails when a
committed contract no longer matches its controllers.

## Regenerate

When a backend API changes, the integrator or the package that changed it regenerates the contract
first (`DLAP_OPENAPI_UPDATE=1 ./gradlew :da-<service>:test --tests '*OpenApiSpecExportTest*' --rerun`
in the main repository), then, from `frontend/` of this repository checked out as `new-ui/` in it:

```bash
npm run gen:api          # rewrite src/api/generated/*.ts from ../../docs/api/openapi
npm run gen:api:check    # fail when the committed types are out of date, change nothing
npm run typecheck        # the callers of a changed endpoint now fail to compile
```

The scripts read the contracts from `../../docs/api/openapi`, which is where they sit when this
repository is the `new-ui` submodule of the main repository. A standalone checkout needs the same
layout (a `docs/api/openapi` folder two levels above `frontend/`).

## Use

```ts
import type { AssetOutputDTO, paths } from '@/api/generated/catalog';

type GetAsset = paths['/api/v1/catalog/assets/{assetId}']['get'];
```

Every schema is also exported at the top level under the name of its Java DTO. `generated.test.ts`
holds type-level checks that `npm run typecheck` enforces.
